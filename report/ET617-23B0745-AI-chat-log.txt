## 2. The app structure to use for any problem statement

Whatever the topic, build these screens:

1. **Landing page:** who it's for, the problem, and the learning objectives written with Bloom's verbs ("Students will *identify*… *apply*… *evaluate*…").
2. **Login / sign-up:** lets you track each learner and shows you remember Assignment 1.
3. **Learner personas page:** 1–2 personas (name, age, context, goal, frustration, what motivates them, which theory explains them).
4. **Learning module:** content broken into short chunks, which is Cognitive Load Theory in practice.
5. **Practice / quiz:** questions tagged by Bloom's level, instant feedback with an explanation, hints for scaffolding, and a retry option.
6. **Progress page:** streaks, mastery per topic, badges. This is the motivation feature.
7. **Analytics dashboard (instructor view):** charts from the clickstream (time per module, quiz accuracy by Bloom's level, where learners drop off, most-missed questions). This is your **evaluation** story.
8. **Design rationale page:** a table of feature → principle → theory. You'll explain your design decisions in the assessment hour, and this page answers that for you.

**Features that make it look professional** (pick what fits the problem):
- Spaced-repetition review queue (memory model: retrieval strengthens long-term memory)
- Adaptive difficulty that moves up a level after two correct answers and offers a hint after a wrong one (zone of proximal development)
- Language toggle, e.g. English/Hindi (persona constraint)
- Works offline with saved progress (persona constraint: patchy internet)
- Dark mode, mobile-first layout, keyboard accessible
- Export the clickstream as CSV (useful for the data-analysis part)
- An optional AI tutor hint, only if an API key is easy to get. Keep it optional so the demo never depends on it.

- The true period for a 75 cm string is T = 2π√(0.75/9.81) = **1.737 s**, so 10 swings should take **17.37 s**.

**Why it's built in (the teaching reason):**

2. **It teaches that tiny differences aren't real effects.** Any change smaller than 0.03 s is labelled *"about the same (the difference is smaller than stopwatch error)"*. So when the mass changes and the period moves from 1.42 to 1.43 s, Sana learns that mass made no real difference.
3. **Repeating a trial checks your timing.** The app says exactly that when the settings are unchanged.
